# WORK VITAL 카피 QA 변경 이력

파일 변경 작업마다 기존 내용을 보존하고 이 문서 맨 아래에 새 기록을 추가합니다. 같은 작업에서 함께 변경한 파일은 하나의 기록에 모두 명시할 수 있으며 이력 파일 갱신도 포함합니다. 설명·논의만 하고 파일을 변경하지 않았다면 기록하지 않아도 됩니다.

문서에 수정안을 쓴 것과 실제 홈페이지에 적용한 것을 구분합니다. 화면 확인·테스트·사용자 검증도 각각 실제 수행한 범위와 결과만 적습니다. ‘문서 작성 완료’를 ‘홈페이지 반영 완료’나 ‘효과 검증 완료’로 기록하지 않습니다.
